# Security and data handling

This repository contains only synthetic test data and public demonstration-system
URLs. It must not contain employer code, production credentials, customer data, or
copied selectors/payloads from private systems.

The default `admin/password` credentials belong to the deliberately public Restful
Booker Platform training application. Override all runtime settings with environment
variables when pointing the framework at another deployment.

If you discover a vulnerability in this portfolio repository, report it privately
to the repository owner. Report issues in Restful Booker Platform to its maintainer;
do not load-test or attempt destructive security testing against the hosted demo.
